# Learning record 格式

Learning record 放在 `./learning-records/`，循序編號：`0001-slug.md`、`0002-slug.md`。第一則要寫時才建目錄。

它是教學版的 ADR：捕捉非顯然的教訓、關鍵洞察、以及學習者自述的既有知識——這些是**計算 ZPD 的依據**。

## 樣板

```md
# {學到了什麼 / 確立了什麼，的簡短標題}

{1–3 句：學到（或確立）了什麼，以及它為什麼改變後續 session 該教什麼。}
```

格式就這樣。一則 learning record 可以只有一段。價值在於記下**這件事現在已知**以及**它為何改變下一步教什麼**，不在於把欄位填滿。

## 選用段落

只在真有價值時加，多數紀錄不需要。

- **Status** frontmatter（`active | superseded by LR-NNNN`）：早先的理解後來被推翻時有用。
- **Evidence**：學習者如何展示了這個理解（答對某問題、完成某練習、引述既有經驗）。這個主張可能被重新檢視時有用。
- **Implications**：這解鎖了或排除了後續 session 的什麼。非顯然時值得記。

## 編號

掃 `./learning-records/` 取最大號 +1。

## 何時寫

任一成立就寫：

1. **學習者展示了對非平凡事物的真正理解** — 不只是接觸過，而是有證據他能正確使用這個概念。這抬高了下一步該教什麼的地板。
2. **學習者自述既有知識**（「這個我已經會了」）— 記下來，後續 session 才不會重教。連他聲稱的**深度**一起記。
3. **一個誤解被糾正** — 學習者原本相信錯的事，現在懂了為什麼錯。這類價值最高：它能預測相關主題上的絆腳石。
4. **mission 因學習而位移** — 學習者發現他在意的其實是別的東西。交叉連結並更新 `MISSION.md`。

### 什麼不算

- **只是「上過」的內容。** 覆蓋率不等於學會。等證據。
- **已經在術語表裡簡潔記過的東西。** 不要重複。
- **逐次 session 的活動日誌。** learning record 不是日記，是決策級的洞察。

## Supersede

後來的紀錄與早先的矛盾（理解變深或被糾正）時，把舊的標 `Status: superseded by LR-NNNN`，**不要刪**。理解如何演化的歷史本身就是訊號。
