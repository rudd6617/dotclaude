# 術語表格式

術語表是這個教學工作區的**權威語言**：所有 lesson、練習、learning record 都遵守它的用語。放在 `./reference/` 下（依 `r-teach` 的編號慣例，如 `0001-glossary.html`）。

建術語表**本身就是學習**：能把一個概念壓縮成緊緻的定義，就是理解的證據。

## 每條的形狀

術語表是 HTML（`./reference/NNNN-glossary.html`），每條給一個 `id` 供 lesson 用 anchor 連進來：

```html
<dl class="glossary">
  <dt id="hypertrophy">Hypertrophy<span class="zh">肌肥大</span></dt>
  <dd>
    在重複訓練中由機械張力與代謝壓力驅動的肌肉生長。
    <p class="avoid">Avoid: 增肌、變壯</p>
  </dd>
</dl>
```

lesson 端連法：`<a href="../reference/0001-glossary.html#hypertrophy">肌肥大</a>`。

以下用純文字表示同樣的內容結構（**內容**約定，與 HTML 標記無關）：

```
Hypertrophy（肌肥大）
  在重複訓練中由機械張力與代謝壓力驅動的肌肉生長。
  _Avoid_: 增肌、變壯

Progressive overload（漸進超負荷）
  隨時間系統性提高肌肉承受的需求，途徑為負重、量或強度。
  _Avoid_: 更努力、升級

RPE（自覺用力程度）
  1–10 的自評，記錄一組有多吃力；10 是力竭，8 代表還剩兩下。
  _Avoid_: 費力分數、強度評分
```

## 規則

- **只在學習者已經理解時才收進來。** 術語表是壓縮後知識的紀錄，不是給他讀來學習的字典。剛被介紹到的概念要等——等到他能正確使用了才升級進來。
- **要有主張。** 同一概念有多個說法時挑一個最好的，其餘列進 `_Avoid_`。語言就是這樣壓縮的。
- **定義要緊。** 一到兩句。講它**是什麼**，不講它做什麼或怎麼做。
- **定義裡優先使用術語表自己的術語。** 一個詞進了表，之後到處都用它，包括在別的定義裡——這是複雜術語之後變好懂的原因。
- **自然叢聚時用子標題分組**（如「解剖」「課表」）。術語本來就內聚時平鋪即可。
- **模糊處明確標註解法。** 該詞在整個領域被寬鬆使用時，記下本工作區的裁定：「本工作區的『組』一律指工作組；熱身另計。」
- **理解變深就改。** 第一週寫的定義到第六週可能是錯的。原地更新，不要留過期條目。
